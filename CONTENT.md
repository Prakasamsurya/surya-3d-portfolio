## 4. Placeholder conventions

Unverified content must be visibly and consistently marked, never filled with plausible-sounding text.

- Use the literal marker `[PLACEHOLDER: <what is needed>]`, for example `[PLACEHOLDER: internship dates]`.
- For unconfirmed usage, use `[PENDING VERIFICATION: <what>]`.
- In typed content data, represent missing values explicitly (for example a `null` value with a status field), not with fabricated defaults.
- Placeholders must be visible in the interface until replaced, and must be easy to find by searching for `PLACEHOLDER` or `PENDING VERIFICATION`.
- Replace a placeholder only with a fact the owner has confirmed. Record the confirmation in `IMPLEMENTATION_STATUS.md`.
